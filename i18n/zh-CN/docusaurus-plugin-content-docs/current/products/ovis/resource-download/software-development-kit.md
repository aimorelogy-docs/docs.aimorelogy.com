# 软件开发套件

以下资源提供 Ovis 固件包、SDK 和 OVIS Web 源代码，以及用于 SDK 编译和 TPU 开发的 Docker 镜像。

| 资源 | 说明 | 链接 |
| --- | --- | --- |
| Ovis 固件 | 适用于 Standard 和 CVBS 硬件的预编译固件。选择与硬件匹配的固件包，解压后即可按照[烧录 OVIS 固件](../getting-started/software-flashing.md)直接烧录，无需自行编译 SDK。 | [GitHub Releases](https://github.com/aimorelogy-ovis/aimorelogy-ovis-sdk/releases) |
| Ovis SDK | SDK 源代码、板级配置、构建脚本与固件打包工具。 | [GitHub 仓库](https://github.com/aimorelogy-ovis/aimorelogy-ovis-sdk) |
| OVIS Web | 开源的浏览器管理界面，用于搜索、初始化和配置 Ovis 设备。 | [GitHub 仓库](https://github.com/aimorelogy-ovis/ovis.web.github.io) |
| Ovis Build Docker | 用于编译 Ovis SDK 的预配置构建环境。 | [Docker Hub](https://hub.docker.com/repository/docker/aimorelogy/ovis-build-docker) |
| Ovis TPU Docker | 用于 Ovis TPU 开发流程的 Docker 镜像。 | [Docker Hub](https://hub.docker.com/repository/docker/aimorelogy/ovis-tpu-docker) |
